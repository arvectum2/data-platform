# Arvectum Data Platform Consumer SDK 0.3.0

## Scope

0.3.0 adds neutral primitives for consumer-owned presets while keeping HTTP consumer contract 1.x unchanged.

## Added

- Python SearchProfile and search_with_profile(...);
- JavaScript searchWithProfile(...);
- Python build_collection_id(...) and JavaScript buildCollectionId(...);
- parity tests for profile forwarding and collection ID composition.

Domain-specific profile values and namespaces remain in consumer repositories.
